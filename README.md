## 報修清單篩選

清單預設顯示最近 20 筆報修，可點選「全部／高／中／低」依緊急程度篩選。切換只使用已載入的資料，不會另外查詢 Supabase。高緊急度的「高」標籤以紅色顯示。

## 安裝報修網頁

先連線開啟網站。Android Chrome 可從選單選「安裝應用程式」或「新增至主畫面」，iPhone Safari 可從分享選單選「加入主畫面」。安裝與離線功能需要 HTTPS 或 localhost。

首次連線載入後，離線時可開啟報修介面。查詢與送出需連線，離線不會排程補送，也不會將報修紀錄寫入離線快取。

本機驗證可在儲存庫根目錄執行 `py -m http.server 8000`，再開啟 `http://localhost:8000/`。修改離線快取的檔案時，請一併更新 `sw.js` 的快取版本，讓瀏覽器安裝新版。
